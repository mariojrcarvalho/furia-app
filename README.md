# Furia Tech

Este projeto foi desenvolvido como parte de um desafio técnico para a empresa **Furia Tech**, com o objetivo de demonstrar habilidades no desenvolvimento de uma landing page funcional e responsiva.

## 🚀 Demonstração

Confira a aplicação ao vivo: [Furia Tech Landing Page](https://furia-app-nine.vercel.app/)

## 📌 Objetivo

O projeto visa apresentar uma página inicial atraente e funcional, destacando as melhores práticas de desenvolvimento web, incluindo:
- **Design responsivo**
- **Interatividade**
- **Boa estrutura de código**
- **Otimização para performance**

## 🛠️ Tecnologias utilizadas

- **HTML5**
- **CSS3**
- **JavaScript**
- **Frameworks ou bibliotecas utilizadas** (React)
